Conexión a Archivos Excel en SharePoint (Método Oficial)

¡No use el conector de Lista de SharePoint!
Si sus datos son libros .xlsx, usar el conector de Listas fallará. Debe usar el conector Carpeta de SharePoint o la URL directa de SharePoint.

Paso a paso en Power BI Desktop:

  1. Vaya a Inicio > Obtener datos > Más...
  2. Seleccione la categoría SharePoint > elija Carpeta de SharePoint > clic en Conectar.
  3. Pegue únicamente la URL raíz del sitio (ej. https://tuempresa.sharepoint.com/sites/GestionCalidad). No incluya rutas de subcarpetas ni el nombre del archivo.
  4. En autenticación, seleccione Cuenta Microsoft / Cuenta Organizacional e inicie sesión con su usuario corporativo.
  5. En la ventana de vista previa, haga clic en Transformar datos.
  6. En Power Query, filtre la columna Folder Path para apuntar a la carpeta exacta y filtre Name para el archivo Excel requerido.
  7. Haga clic en el icono binario [Binary] de la columna Content para extraer las hojas del libro.

Código M de Referencia (Plantilla):

let
    Origen = SharePoint.Files("https://tuempresa.sharepoint.com/sites/GestionCalidad", [ApiVersion = 15]),
    FiltroCarpeta = Table.SelectRows(Origen, each [Folder Path] = "https://tuempresa.sharepoint.com/sites/GestionCalidad/Documentos Compartidos/Bases/"),
    FiltroArchivo = Table.SelectRows(FiltroCarpeta, each [Name] = "Base_Nacional_Novedades.xlsx"),
    Contenido = FiltroArchivo{0}[Content],
    LibroExcel = Excel.Workbook(Contenido, null, true),
    HojaNovedades = LibroExcel{[Item="Novedades", Kind="Sheet"]}[Data],
    EncabezadosPromovidos = Table.PromoteHeaders(HojaNovedades, [PromoteAllScalars=true])
in
    EncabezadosPromovidos

Conexión a Lista de SharePoint Online

  1. En Power BI Desktop, haga clic en Obtener datos > SharePoint Online List.
  2. Ingrese la URL del sitio (ej. https://tuempresa.sharepoint.com/sites/GestionCalidad).
  3. En la opción de Versión de API, seleccione 2.0 (Recomendado) para mayor velocidad y mejor detección de tipos.
  4. Autentíquese con Cuenta Microsoft corporativa autorizada.
  5. En el Navegador, marque la casilla de la lista requerida y haga clic en Transformar datos.

Conexión a Archivo Excel Local o Carpeta de Red

Si los archivos están en su disco duro o en un servidor local (\\servidor\calidad\...):

  1. Inicio > Obtener datos > Excel.
  2. Seleccione el archivo y elija la hoja o tabla correspondiente.
  3. Advertencia: Si usa una ruta como C:\Users\SuNombre\..., al mover el archivo a otro equipo la actualización fallará. Se recomienda parametrizar la ruta de origen en Power Query.

Cómo Averiguar qué Fuente Existe Actualmente

1. Abra el archivo PBIX existente.

2. Clic en Transformar datos > menú lateral de consultas > seleccione la primera consulta.

3. En Pasos aplicados a la derecha, haga clic en el paso Origen y observe la barra superior de fórmulas fx:

  • Si dice SharePoint.Files: son archivos Excel en SharePoint.
  • Si dice SharePoint.Tables: es una Lista de SharePoint.
  • Si dice Excel.Workbook(File.Contents(...)): es un archivo en disco local o red.

Transformación y Calidad (ETL)

Guía Práctica de Power Query

Procedimientos esenciales de preparación, tipado y limpieza de datos antes de cargar al modelo.

Conceptos Fundamentales: Anexar vs Combinar

Anexar Consultas (Append)

Apila filas de una tabla debajo de otra (equivalente a UNION ALL). Solo debe usarse si las tablas tienen la misma granularidad y columnas equivalentes (ej. Base Nacional y Base Cartagena de Novedades).

Combinar Consultas (Merge)

Une columnas horizontalmente mediante una clave común (equivalente a LEFT JOIN). Útil para enriquecer la tabla de hechos con maestros o catálogos.

Patrones M Recomendados para Calidad de Datos

// 1. Limpieza de texto en Placa (Evitar discrepancias por espacios o minúsculas)
= Table.TransformColumns(PasoPrevio, {{"Placa", each Text.Upper(Text.Trim(_)), type text}})

// 2. Tipado estricto de fechas (Evitar errores de formato regional)
= Table.TransformColumnTypes(PasoPrevio, {{"Fecha_Operacion", type date}}, "es-CO")

// 3. Reemplazo de errores por nulos elegantes en cantidades
= Table.ReplaceErrorValues(PasoPrevio, {{"Cantidad_Faltante", 0}})
Cálculo y Lógica de Negocio

Guía de Modelado Relacional y DAX

Fórmulas DAX robustas, control de contexto de filtro y esquemas en estrella.

Reglas de Oro DAX para este Proyecto

  • Usar Medidas Explícitas: Nunca arrastre columnas al área de valores esperando agregaciones implícitas automáticas.
  • Siempre DIVIDE(): Previene el error NaN o Infinity cuando el denominador es 0 o está vacío.
  • Cuidar la granularidad: COUNTROWS() cuenta filas de registros; DISTINCTCOUNT() cuenta identidades únicas de camiones o transferencias.

Medidas Principales Listas para Sustitución

// KPI: Total Faltantes (Unidades)
Total Faltantes = 
CALCULATE(
    SUM(f_Novedades[Cantidad_Unidades]),
    KEEPFILTERS(f_Novedades[Tipo_Novedad] = "Faltante")
)

// KPI: % Faltantes (Con Denominador Seguro)
% Faltantes = 
DIVIDE(
    [Total Faltantes],
    [Total Unidades Despachadas], // Sustituir por la medida de denominador oficial
    BLANK()
)

// KPI: Vehículos Únicos que Llegaron
Vehiculos que Llegaron = 
DISTINCTCOUNT(f_Llegadas[Placa_Vehiculo])

// KPI: Vehículos con Novedades
Vehiculos con Novedad = 
CALCULATE(
    DISTINCTCOUNT(f_Novedades[Placa_Vehiculo])
)

// KPI: Ranking Top 5 Dinámico
Ranking Vehiculo = 
IF(
    NOT(ISBLANK([Novedades por Vehiculo])),
    RANKX(
        ALLSELECTED(d_Vehiculo[Placa_Vehiculo]),
        [Novedades por Vehiculo],
        ,
        DESC,
        Dense
    )
)

Eficiencia de Procesos

Automatización del Proceso de Actualización

Estrategia para eliminar las tareas de copiar, pegar y consolidar manualmente.

Flujo Actual vs Flujo Futuro Propuesto

Flujo Actual (Manual y Propenso a Error)

1. Descargar archivo nacional y archivo regional.
2. Copiar registros de una hoja a otra.
3. Completar datos manualmente con otras hojas.
4. Pegar en la base de novedades.
5. Abrir Power BI y actualizar.

Flujo Futuro Propuesto (Automatizado)

1. Los usuarios registran directamente en SharePoint (Carpeta o Lista).
2. Power Query realiza la consolidación y limpieza automáticamente en memoria.
3. Power Automate (si está autorizado) notifica novedades críticas.
4. Power BI Service actualiza programadamente sin intervención manual.

Base de Conocimiento

Solución de Problemas Frecuentes

Diagnóstico rápido y acciones seguras ante los fallos más comunes en Power BI y SharePoint.

1. Error: "No se puede autenticar con las credenciales proporcionadas" en SharePoint

Causa: Power BI guardó credenciales anónimas o de Windows en lugar de la cuenta institucional de Microsoft 365.

Acción Segura: Vaya a Archivo > Opciones y configuración > Configuración del origen de datos > Seleccione la URL de SharePoint > Clic en Borrar permisos. Luego haga clic en Actualizar y elija Cuenta Microsoft para iniciar sesión.

2. Un filtro funciona en una página pero no se aplica en las demás

Causa: El segmentador no está sincronizado en el panel lateral o proviene de columnas no vinculadas en el modelo.

Acción Segura: Active Ver > Sincronizar segmentadores y marque las casillas de sincronización. Compruebe que todas las tablas usen la misma dimensión compartida (ej. d_Vehiculo[Placa]).

3. Las fechas se cargan como Texto o generan error de conversión

Causa: Incompatibilidad de configuración regional (ej. formato día/mes/año vs mes/día/año de Windows).

Acción Segura: En Power Query, haga clic derecho sobre el encabezado de fecha > Cambiar tipo > Usando la configuración regional... > Elija Tipo: Fecha y Configuración: Español (Colombia) o la del país de origen.

4. Las cifras de vehículos aumentan inesperadamente

Causa: Se está usando COUNT() o COUNTROWS() sobre la tabla de novedades en lugar de DISTINCTCOUNT() sobre las placas o viajes.

Acción Segura: Revise la fórmula DAX. Si una placa tuvo 10 novedades, contar filas devolverá 10 en vez de 1 camión.

5. La tabla de detalle muestra registros duplicados

Causa: Se creó una relación de varios a varios (*:*) entre dos tablas de hechos sin una dimensión intermedia, generando producto cartesiano.

Acción Segura: Nunca fuerce una relación de varios a varios. Cree una tabla intermedia con valores únicos de Placas o Transferencias y relacione 1 a varios hacia cada hecho.
